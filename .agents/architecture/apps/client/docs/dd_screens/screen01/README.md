# Screen01 — Mẫu Detail Design (cùng Screen01 trong module1)

**Loại:** `DESIGN_EXAMPLE`, không thêm screen mới.

## Điền khi có yêu cầu được duyệt

- Screen ID, route, mục đích, actor, quyền, entry conditions.
- UI elements, state (idle/loading/empty/error/success), validation và accessibility.
- Event → guard → model/view state → API → response/error → navigation.
- Data mapping, responsive rules, test cases và negative paths.

Dùng skill [`create-dd-screen`](../../../../../../skills/create-dd-screen/SKILL.md) để sinh DD thực. Mẫu không áp đặt Angular/React hoặc design system.
