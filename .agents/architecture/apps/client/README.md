# Folder mẫu: `apps/client/`

**Trách nhiệm:** Một web client TypeScript minh họa, không bắt buộc framework hoặc layout đối với dự án khác.

**Mức bằng chứng:** `TEMPLATE_ONLY`, không phải cây source đã được xác minh.

## Folder con

- [`docs/`](docs/README.md) — Thiết kế UI và contracts ở mức expected.
- [`src/`](src/README.md) — Client source root theo ví dụ; checkout đích có thể dùng tên bất kỳ.

**Khi onboarding:** thay cây ví dụ này bằng `project/tree/` sinh từ repository thật; không tự thêm folder vào source.
