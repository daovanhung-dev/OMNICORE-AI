# Kiểm định kiến trúc
`python3 .agents/validators/validate_architecture.py --backend <goc-be> --frontend <goc-fe>` kiểm tra hồ sơ FastAPI SQL và TypeScript: BE-001/002/003/005/007/010, FE-001/005/006/008/010. Chỉ báo `PASS_STATIC` khi bộ phân tích có sẵn và không phát hiện vi phạm thuộc phạm vi kiểm tra. Không kiểm định mọi alias, dynamic import, SQL dựng động, ngữ nghĩa, quyền, transaction hoặc hợp đồng API. Các mục đó phải review và chạy kiểm thử. Hồ sơ khác chưa có adapter được xác minh; không dùng kết quả này làm chứng cứ cho chúng. Kiểm thử dương/âm: `python3 -m unittest discover -s .agents/validators/tests`.
