# Fix bug report template

- Bug ID, severity, user impact, affected version/environment.
- Expected vs actual, reproduction confidence.
- Root cause and decisive evidence (file:line, call path, test, sanitized logs).
- Changed file(s), why change in this owning layer, migration/rollback impact.
- Regression test file/command/expected vs result; linked test/build results and warnings.
- Limitations, unresolved risks, what is not verified, next owner/action.

Never reveal secrets or copy raw personal/production data into worklog.
