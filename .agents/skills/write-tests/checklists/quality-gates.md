# Cổng chất lượng — Testing

- [ ] Requirement & source xác thực, test level phù hợp rủi ro.
- [ ] Happy, invalid, forbidden, not-found, failure, boundary cases liên quan.
- [ ] Test environment isolated, cleanup fixture by created IDs.
- [ ] Có command/exit/status thật; fake ≠ live; unrun tests ghi NOT_RUN.
- [ ] Assertions đúng expected contract, không bị sửa để hợp bug.
- [ ] Test report có scope, remaining gaps, warnings.
